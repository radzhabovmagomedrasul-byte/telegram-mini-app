# ⚡ Быстрый деплой на Vercel - Пошаговая инструкция

## 🎯 Способ 1: Через Vercel CLI (Самый быстрый)

### Шаг 1: Авторизация

Откройте PowerShell в папке проекта и выполните:

```powershell
vercel login
```

1. Откроется браузер или покажется ссылка
2. Откройте ссылку в браузере: `https://vercel.com/oauth/device?user_code=XXXX-XXXX`
3. Войдите в аккаунт Vercel (или создайте новый на https://vercel.com)
4. Подтвердите авторизацию

### Шаг 2: Деплой

После авторизации выполните:

```powershell
vercel --prod
```

Или используйте скрипт:

```powershell
.\deploy.ps1
```

### Шаг 3: Получите URL

После деплоя вы увидите URL вида:
```
✅ Production: https://your-app-name.vercel.app
```

**Скопируйте этот URL** - он понадобится для подключения к боту!

## 🎯 Способ 2: Через веб-интерфейс Vercel (Проще, без CLI)

### Шаг 1: Подготовка GitHub репозитория

1. Создайте репозиторий на GitHub:
   - Откройте https://github.com/new
   - Создайте новый репозиторий (например: `telegram-finance-app`)

2. Загрузите код в GitHub:

```powershell
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ваш-username/telegram-finance-app.git
git push -u origin main
```

### Шаг 2: Импорт в Vercel

1. Откройте https://vercel.com
2. Нажмите **"Add New..."** → **"Project"**
3. Выберите ваш GitHub репозиторий
4. Нажмите **"Import"**
5. Vercel автоматически определит настройки:
   - Framework: Vite
   - Build Command: `npm run build`
   - Output Directory: `dist`
6. Нажмите **"Deploy"**

### Шаг 3: Получите URL

После деплоя (обычно 1-2 минуты) вы получите URL:
- `https://your-app-name.vercel.app`

**Скопируйте этот URL!**

## 🤖 Подключение к Telegram Bot

### Шаг 1: Откройте BotFather

1. Откройте Telegram
2. Найдите [@BotFather](https://t.me/BotFather)
3. Отправьте команду `/newapp`

### Шаг 2: Создайте Mini-App

Следуйте инструкциям BotFather:

1. **Выберите вашего бота** (или создайте нового через `/newbot`)
2. **Title:** `Учет финансов` (или любое другое название)
3. **Short name:** `finance` (будет использоваться в URL)
4. **Description:** `Приложение для учета личных финансов`
5. **Photo:** (опционально) Загрузите иконку 640x360px
6. **Web App URL:** Вставьте ваш URL из Vercel (например: `https://your-app-name.vercel.app`)
7. **GIF:** (опционально) Анимированная превью

### Шаг 3: Проверьте работу

1. Откройте вашего бота в Telegram
2. Нажмите на кнопку с Mini-App (обычно в меню или под кнопкой "Start")
3. Приложение должно открыться!

## 🔧 Дополнительные настройки

### Автоматический деплой при обновлении кода

Если вы используете GitHub:
1. Vercel автоматически задеплоит новую версию при каждом `git push`
2. Каждый коммит создаст превью-версию
3. Слияние в `main` создаст продакшен-версию

### Переменные окружения

Если нужно изменить настройки Supabase:
1. Откройте проект в Vercel Dashboard
2. Перейдите в **Settings** → **Environment Variables**
3. Добавьте переменные:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. Перезапустите деплой

**Примечание:** В проекте уже настроены значения по умолчанию, поэтому это необязательно.

## 🆘 Решение проблем

### Проблема: "The specified token is not valid"

**Решение:** Выполните `vercel login` заново

### Проблема: Mini-App не открывается

**Решение:**
1. Проверьте, что URL использует HTTPS
2. Убедитесь, что URL правильный в BotFather
3. Проверьте консоль браузера на ошибки

### Проблема: Ошибка сборки

**Решение:**
1. Убедитесь, что все зависимости установлены: `npm install`
2. Проверьте, что проект собирается локально: `npm run build`
3. Проверьте логи деплоя в Vercel Dashboard
