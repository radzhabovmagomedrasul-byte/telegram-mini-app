# Changelog

## [2.0.0] - 2024

### Добавлено

- ✅ **Локальное хранение данных** - все данные теперь хранятся в localStorage браузера
- ✅ **Автоматический ID пользователя** - создается при первом запуске приложения
- ✅ **Firebase синхронизация** - резервное копирование и восстановление данных через Firebase Realtime Database
- ✅ **AI-помощник** - анализ трат и персональные советы по оптимизации бюджета
- ✅ **Экспорт/Импорт данных** - поддержка форматов JSON и CSV
- ✅ **Расширенная аналитика** - графики по категориям и времени за месяц, квартал, год
- ✅ **Автоматическое определение темы** - следование системным настройкам устройства
- ✅ **Резервное копирование** - автоматическое и ручное в Firebase
- ✅ **Удаление профиля** - вручную через настройки или автоматически через 1 год неактивности

### Удалено

- ❌ **Supabase авторизация** - больше не требуется регистрация через email/password
- ❌ **Supabase база данных** - заменена на localStorage + Firebase синхронизация

### Изменено

- 🔄 **Архитектура хранения данных** - переход с Supabase на localStorage + Firebase
- 🔄 **Система авторизации** - автоматическое создание локального ID
- 🔄 **Навигация** - добавлена вкладка "AI" для AI-помощника
- 🔄 **Настройки темы** - добавлена опция автоматического определения по системным настройкам

### Технические детали

- Добавлены новые зависимости: `firebase`, `recharts`, `papaparse`, `date-fns`
- Удалена зависимость: `@supabase/supabase-js`
- Созданы новые сервисы:
  - `localStorageService.js` - работа с локальным хранилищем
  - `firebaseService.js` - работа с Firebase
  - `dataSyncService.js` - синхронизация данных
  - `exportImportService.js` - экспорт/импорт данных
  - `aiAssistantService.js` - AI-анализ трат
- Обновлен `transactionService.js` - теперь работает с localStorage
- Обновлен `ThemeContext.jsx` - добавлена поддержка автоматической темы

### Миграция данных

Если у вас были данные в Supabase, их нужно будет экспортировать и импортировать через новую систему экспорта/импорта.
